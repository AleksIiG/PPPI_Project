Проблема:
“У наші дні великою проблемою є недостатня кількість спорту в житті людей або незнання як правильно побудувати систему тренувань. Наша команда хоче вирішити цю проблему та розробити додаток по відслідковуванню тренувань, створенню шаблонів з вибраних вправ або вибором готових.”

Аудиторія:
Розрахована для людей, які вже займаються або хочуть почати займатись.

Рішення:
Я бачу готовий продукт, як сайт де будуть готові шаблони з списком тренувань (офіційним та створені користувачами), інструмент для створення власних шаблонів.


Цінність MVP:
Наше рішення буде вирізнятись серед подібних тим, що у ньому буде база вже готових шаблонів для різних цілей де можна буде вибрати план з детальним описом кожної вправи. Також там можна буде відслідковувати свій прогрес.

Non-goals:
Додати відслідковування прогресу по типу вправа та діаграма прогресу у вазі при одиничному повторі.


Ризики:
Ризик тут лише, якщо наша команда не зробить проект людство залишиться без ще одного сайту для тренувань та нам не поставлять оцінку.

Метрики успіху:
Ми вважатимемо проект успішним, якщо на нашому сайті буде зручний інтерфейс зрозумілий користувачеві, гарний дизайн та якісні готові шаблони для різних цілей розробленні з передовими тренерами(Арнольд Шварценеггер, Ронни Колеман та Chat GPT)
